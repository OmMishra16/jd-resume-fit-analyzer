Job Title: Junior Backend Engineer (Python)

About the role:
We are a fast-growing fintech startup looking for a Junior Backend Engineer to help build
and scale our payments platform. You will work closely with senior engineers to design APIs,
write clean and testable code, and ship features that thousands of users rely on every day.

Responsibilities:
- Design, build, and maintain RESTful APIs using Python (FastAPI or Django).
- Write well-tested, maintainable code and participate in code reviews.
- Work with relational databases (PostgreSQL) and write efficient SQL queries.
- Containerize services with Docker and help maintain CI/CD pipelines.
- Collaborate with frontend and product teams to deliver end-to-end features.
- Debug production issues and improve system reliability.

Must-have qualifications:
- 1-3 years of experience building backend services in Python.
- Solid understanding of REST API design and HTTP fundamentals.
- Experience with a relational database (PostgreSQL, MySQL).
- Familiarity with Git and collaborative development workflows.
- Understanding of writing unit/integration tests.

Nice-to-have:
- Experience with Docker and cloud platforms (AWS or GCP).
- Exposure to message queues (Kafka, RabbitMQ, or Redis).
- Knowledge of CI/CD tools (GitHub Actions, GitLab CI).
- Interest in fintech / payments domain.

Location: Bengaluru (Hybrid)
Employment Type: Full-time
